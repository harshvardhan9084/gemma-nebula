# gemma-nebula
you have to make it a iterative self developer

create a webapp that use gemini gemma 4 31b model to chat and it works inside an intelligent agent which can iteratively perform code execution in it's own code through github repository using RAG to ensure high accuracy for complex software development tasks. initially we have just a basic interface of the app but inside, it contains a vast technology for an intelligent AGENT. specifically designed to automate debugging, refactoring, and feature implementation workflows. then the user can iteratively add features, UI, UX etc with natural language prompts and clear, concise instructions for the AI agent. This should integrate directly with GitHub to streamline repository management and pull request creation. enabling automated code reviews and direct deployments to production environments seamlessly. for faster delivery cycles. This will significantly improve developer velocity and project transparency. This will optimize the development lifecycle and reduce bottlenecks. By leveraging these tools, we can ensure consistent code quality and scalability.
TL;DR - this webapp own an AGENT a chat preview for that, where user can ask the AGENT to add another page in this own webapp - the agent first make changes into the code, push to github, the webapp will reloads automatically. for example, user could ask agent to create a new page named 'notes' in the webapp itself - agent understands, HITL, update the code, push to github, webapp reloads automatically with the new feature
